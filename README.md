Expense tracker web app built with ASP.NET Core MVC. You can add, edit, delete and list expenses.

## Stack

- .NET 8, ASP.NET Core MVC with Razor views
- Entity Framework Core with an in-memory database, so the data resets when the app stops
- Repository and service layers (`Infrastructure/Repository`, `Services`)
- Bootstrap and jQuery validation

## Run locally

```bash
cd SpendSmart
dotnet run
```
